  • Eco real con retroalimentacion — repeticiones que se desvanecen gradualmente, en vez de una sola repeticion.
  • Reverberacion (sala / catedral / estudio) — simula el espacio donde "suena" la voz.
  • Filtro de telefono / radio antigua — recorta graves y agudos para sonar como una llamada o transmision vieja.
  • Distorsion / autotune — efecto robotico mas realista tipo vocoder o correccion de tono.
  • Coro (chorus) — varias copias de la voz ligeramente desafinadas para dar sensacion de grupo.
  • Bajo el agua — filtro pasa-bajos con modulacion, sonido apagado y ondulante.
  • Voz invertida — reproduce el audio generado al reves.
  • Ecualizador manual — graves / medios / agudos ajustables con controles independientes.

Nota tecnica: los presets actuales (Robot, Ardilla, Gigante, etc.) usan velocidad, tono y volumen, que es lo que expone la Web Speech API del sistema. Efectos como reverberacion, eco real o filtros de frecuencia necesitan procesar la onda de audio generada (por ejemplo con Web Audio API sobre un motor de voz que entregue el audio en bruto, o un servicio de voz en la nube).
